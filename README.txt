ШКОЛЬНЫЙ ЖУРНАЛ ПОСЕЩАЕМОСТИ

Стек: обычный HTML/CSS/JavaScript + Supabase PostgreSQL + Vercel.

1. Создайте проект в Supabase.
2. Откройте SQL Editor и вставьте весь текст из database.sql. Нажмите Run.
3. В Supabase откройте Project Settings -> API. Скопируйте Project URL и anon public key.
4. Откройте app.js и замените:
   ВСТАВЬТЕ_URL_СЮДА
   ВСТАВЬТЕ_ANON_KEY_СЮДА
5. Загрузите папку проекта в GitHub.
6. В Vercel нажмите Add New -> Project, выберите репозиторий и Deploy.
7. Получите ссылку вида https://...vercel.app.

ВАЖНО: эта версия намеренно без авторизации. Любой, кто получит ссылку, сможет менять данные. Не заносите сюда чувствительные сведения, если сайт будет доступен всему интернету. Для настоящей школы лучше добавить вход для учителей.
